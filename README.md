# CyberQuest PRO 6.0

Plataforma de estudos de cibersegurança com 89 aulas, 356 perguntas, 18 laboratórios simulados, provas e XP.

Abra `index.html` no navegador para estudar. O progresso fica salvo no navegador, e pode ser exportado na plataforma. Pratique testes de segurança somente em ambientes próprios ou autorizados.
